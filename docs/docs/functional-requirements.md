# Functional Requirements

| ID | Requisito | Prioridad | MVP |
|---|---|---:|---:|
| FR-001 | El sistema debe registrar e identificar usuarios. | P0 | Sí |
| FR-002 | Cada usuario debe tener una biblioteca privada. | P0 | Sí |
| FR-003 | El sistema debe aceptar PDF, DOCX y TXT con límites configurables. | P0 | Sí |
| FR-004 | El sistema debe validar tipo, tamaño, nombre y contenido del archivo. | P0 | Sí |
| FR-005 | El procesamiento debe ser asíncrono y exponer estados `UPLOADED`, `PROCESSING`, `READY`, `FAILED`. | P0 | Sí |
| FR-006 | El sistema debe extraer y normalizar texto conservando metadatos de origen. | P0 | Sí |
| FR-007 | El sistema debe generar resúmenes estructurados con referencias al documento. | P0 | Sí |
| FR-008 | El sistema debe generar flashcards estructuradas con referencias al documento. | P0 | Sí |
| FR-009 | El sistema debe permitir practicar flashcards y registrar el resultado. | P0 | Sí |
| FR-010 | El sistema debe impedir el acceso cruzado entre usuarios. | P0 | Sí |
| FR-011 | El sistema debe eliminar un documento y sus artefactos derivados de forma consistente. | P0 | Sí |
| FR-012 | El sistema debe conservar versión de prompt, modelo y esquema de cada generación. | P1 | Parcial |
| FR-013 | El sistema debe ofrecer chat con recuperación semántica y atribución de fuentes. | P1 | No |
| FR-014 | El sistema debe generar cuestionarios de varios tipos. | P1 | No |
| FR-015 | El sistema debe calcular progreso y debilidades de aprendizaje. | P2 | No |
| FR-016 | El sistema debe ofrecer recomendaciones y repetición espaciada. | P2 | No |
