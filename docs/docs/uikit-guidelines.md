# UIKit Guidelines

El MVP adopta el sistema visual `SmartStudy Focus` definido en Stitch.

- Primario: `#4F46E5`; interacción hover: `#4338CA`.
- Acento de IA y trazabilidad: `#0D9488`.
- Éxito: `#10B981`; advertencia: `#F59E0B`; error: `#BA1A1A`.
- Headlines: Plus Jakarta Sans.
- Texto y formularios: Inter.
- Radio base: 8px; cards: 14–16px; estados continuos: pill.
- Fondo: `#F8FAFC`; superficies: `#FFFFFF`; borde: `#E2E8F0`.
- Focus ring: indigo con offset visible, sin desplazamiento de layout.
- Iconografía: Unicons Line de IconScout mediante `@iconscout/unicons`; no se usan glifos Unicode como iconos de interfaz.

Las pantallas se diseñaron y organizaron en el proyecto Stitch `SmartStudyAI Web Platform`.
