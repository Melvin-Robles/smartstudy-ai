# STEP 00 — User Stories

Las historias de STEP 00 están definidas en [../../user-stories.md](../../user-stories.md). El conjunto candidato del MVP es US-001 a US-006.

## Definition of Done común

- Especificación y criterios aprobados.
- Pruebas unitarias, integración, contrato, E2E y seguridad asignadas según riesgo.
- Implementación alineada con Clean Architecture y UIKit.
- Pruebas ejecutadas con evidencia.
- Lint, build y revisión de seguridad aprobados.
- Documentación y trazabilidad actualizadas.
